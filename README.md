# flapy-bird
The game is about a flying bird that flys between pips and all pips have diffrent sizes. If the bird tuches a pipis then you lose by pressing "R" you can restart the game and try again. The bird flys when it hears sound, if the sound is short then it flys not thet high but if the sound is long then it flys high. 
We used python to create this game.
